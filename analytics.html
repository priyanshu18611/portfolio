Year-Over-Year Sales Variance Measure:

YoY_Sales_Variance_% =
VAR CurrentSales = CALCULATE(SUM(Sales[Amount]), DATESYTD('Date'[Date]))
VAR PreviousSales = CALCULATE(SUM(Sales[Amount]), SAMEPERIODLASTYEAR('Date'[Date]))
RETURN
DIVIDE(CurrentSales - PreviousSales, PreviousSales, 0)

Window functions, Common Table Expressions (CTEs), and star-schema ingestion models

WITH RegionalAggregates AS (
  SELECT region, category, SUM(sales_amount) as total_revenue,
    DENSE_RANK() OVER(PARTITION BY region ORDER BY SUM(sales_amount) DESC) as rank_pos
  FROM enterprise_dw.fact_sales
  GROUP BY region, category
)
SELECT * FROM RegionalAggregates WHERE rank_pos = 1;
